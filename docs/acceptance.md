# 独立验收与共享场景

## 当前可执行验证

`packages/contracts/test/contracts.test.ts` 校验协议 Schema、十一条规范事件时间线、路径语法、必需检查与证据映射、输入基线和错误格式。fixture 是合成数据，hash 为占位符，不能作为真实模型、构建或浏览器验证的证据。

```bash
pnpm install --frozen-lockfile
pnpm check
pnpm test
```

## 三套替身的责任

| 替身 | 所有者 | 模拟边界 | 不允许 |
| --- | --- | --- | --- |
| Mock API | 前端 | 浏览器实际调用的 `/api/v1` | 组件直接读 fixture 冒充请求成功 |
| Fake Runtime | 后端 | 真实内部 HTTP，按 executionId 启动/查询/事件/回答/取消/下载 | 直接改后端数据库或绕过 Agent client |
| Fake DSH | Agent | DSH adapter 的命令与通知 | 绕过 Runtime HTTP、验证与产物路径直接宣告成功 |

替身复用共享 DTO 和场景含义，而不要求复用真实服务实现。每套均可控制时钟、暂停点和故障注入，以确定性重现竞态，不依赖固定 sleep 等待。

## 后端独立测试最低要求

- 创建 Run、预占配额、幂等记录、派发 outbox 在事务内；双击只创建一次。
- Runtime 已启动但 API 未收到确认，重试不出现重复执行或扣费。
- `(executionId,sourceSeq)` 重复、乱序传输均不产生重复公开事件；缺口先补齐，不能直接吞掉。
- 原子快照与事件游标对应；刷新不会丢部分文本或 Attention。
- waiting_input 期间保留项目锁；同项目排队、其他项目可继续；恢复也受计算槽限制。
- 取消先提交则禁止迟到发布；发布先提交则保留成功，不产生“取消成功但已发布”的假状态。
- outbox、事件写入、文件落盘、发布事务前后崩溃可恢复；无法确认停止时不释放锁。
- 所有文件、版本、事件、问题、下载、恢复接口检查归属；隐藏 ID 不算权限控制。

## Agent 独立测试最低要求

- 同 executionId 相同请求重复启动只运行一次，不同体冲突。
- 源事件持久化、有序、可重放；完整消息能覆盖部分消息。
- Attention 可回答、可取消；不把 SDK 网络超时当执行停止。
- required 检查真实执行并有结果；修复上限和模型步数到达时停止。
- manifest 哈希与真实文件一致，拒绝 symlink、路径逃逸、超限文件。
- shell/browser 环境无模型/内部认证 Key；进程停止和重启恢复行为可验证。
- Fake DSH 测试与真实 Key 烟测分离。COMPATIBILITY.md 明确已验证版本和不支持的能力。

## 前端独立测试最低要求

- 仅 `dev:mock` 即可覆盖 S01–S10；无需 DSH、后端或 Key。
- 实际断言 HTTP 请求路径、幂等键、回答 revision、取消响应处理，而非只断言 UI 文案。
- 按项目 seq 去重，切项目不会串流；终态再取快照后停止该任务的高频轮询。
- 失败/取消不切换预览；只有 version.published 或快照可以切版本。
- 历史代码作为文本展示，不能在工作台执行；模型文本不变成 HTML、脚本或任意预览 URL。
- Mock 不默认进入生产 bundle 行为；生产接口失败显示真实错误，不能回退假成功。

## 真实端到端验收

1. 体验码进入工作台，生成便签墙，至少得到两个 React 源文件及真实构建产物。
2. 页面内新增、编辑便签，刷新后数据保留；实际拖拽行为单独检查。
3. 对话要求增加搜索，生成第二版，展示修改与检查结果。
4. 受控测试注入一个构建错误，看到失败证据、修复及再次通过；不得把演示 fixture 当真实记录。
5. 第二次任务失败/取消时第一版仍可操作。
6. 回滚创建新版本，在恢复版继续修改；下载源码可独立安装构建。
7. 重启 API 后仍可查看项目、对话与成功版本；Agent 重启后的执行状态按真实能力报告。
8. 外网链接打开、刷新、模块资源、预览存储、Cookie 与权限均通过；源码和浏览器请求中没有服务密钥。
