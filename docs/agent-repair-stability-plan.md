# Agent验证与修复闭环稳定性：主管基线候选

状态：本轮本机实现、独立验证与服务升级已完成，详见 `docs/repair-stability-verification.md`。本文件保留主管基线与边界，不代表用户旧失败任务已成功。替代把俄罗斯方块几个报错逐点修正就宣布稳定的交付标准。旧用户任务仍是失败，独立临时样例不能替代用户成功记录。

## 目标与边界

一份已授权需求，在原有限额内，由Agent持续规划、生成、验证、解释失败、决定修复及重新验证，直到可发布或具有明确原因的停止。稳定不等于无限重试或保证任意应用成功，而是每一失败有确定、可观察、可恢复且守住权限的下一步。

保留需求授权、固定验收与预算语义；执行Worker不得改标准使自己通过。规划冻结前可在原规划预算内纠正格式/语义。冻结后区分代码错误与验收计划错误；涉及改变冻结标准时必须沿适用确认流程，不能悄悄替换测试。旧任务/原报告不重写，失败候选不是已发布版本。

## 统一决策应覆盖的阶段

`planning → generate → workspace verification → export → independent clean verification → finalize`

各阶段应进入共同的失败分类/决策机制，而非各自捕获后随意终止。实现方案须明确：输入证据、允许动作、剩余时间/Token/模型步/修复次数、不可变证据引用、取消与恢复行为。代码修复后的成功必须来自同冻结计划的新源码及新复验，不得复用旧绿灯。

| 失败类别 | 决策要求 |
| --- | --- |
| 冻结前结构/语义规划错误 | typed、可操作反馈与合法表达范例；在剩余规划预算内纠正 |
| 类型/构建/页面运行时/required行为错误 | 基于真实失败证据修复代码，重新验证 |
| 精确导出中的required行为错误 | 同一受限修复闭环，修复后重新打包并独立复验 |
| 观测不确定或验收依据错误 | 不得当作代码已通过；给稳定性证据，按计划纠正边界处理 |
| 安装/依赖网络/工具链/哈希或权限错误 | 明确基础设施/完整性分类，不让模型反复改应用碰运气 |
| 连续相同失败/无源码进展 | 检测无进展，升级诊断或明确停止，不能空转直到耗尽 |
| 预算/取消/中断 | 记录实际用量或未知/下界、保存可用checkpoint、确认计算停止；不自动追加额度 |

## 三线职责

- Agent：完整状态转移和统一RepairController、证据与修复上下文、稳定观测、无进展/预算控制、恢复安全；提供阶段注入和真实浏览器回归。
- API：需求/源码/验收/Run授权与发布权威；重试与重启幂等、配额一次结算、报告/证据不可变、进度投影；如需新协议先冻结独立版本，禁止消费者私扩。
- Web：每轮阶段/失败/下一步/停止原因可读，区分工作目录和独立复验；可找到每一历史失败报告，刷新/切项目/迟到响应不混淆任务；不把5/5等局部检查当发布结果。
- 主管：冻结共同基线、审查实现、独立验证、集成与保留用户数据的本机升级；不进入三线代码实现。

## 交付门禁

必须以通用故障矩阵验证：规划错误→纠正；生成错误→修复；工作目录失败→多轮修复；工作目录通过但clean失败→修复→双侧通过；重复失败/无进展；修复期间取消；预算不足；严格重启不重放/不扣重复额度；源码/计划/报告hash错配failclosed。验证器另有动画瞬态false-pass反例。

真实模型验收使用独立临时空间、明确次数和原预算，重现用户完整需求；不能将手写fixture、单个成功样例或Schema通过称为整条能力稳定。用户原任务保持原始失败状态，任何新用户构建必须有对应授权。


## 已冻结的本轮接口与策略

- 复用现有strict执行/交付DTO、phase/message/report/evidence，不前置新公共状态或大协议；Agent私有controller不替代API业务状态机。
- 可修的clean行为失败先生成nonfinal报告，保持原Run/writer，进入原剩余修复次数；终止才final。旧clean轮的ZIP/报告/证据独立不可变，当前报告单cleanBuild指最新，仍需按source/plan/hash审计。
- 基础设施自动重试本轮为0；重启维持stop/reconcile→interrupted，不重放模型，不新增自动应用旧响应恢复路径。
- 冻结后改变Plan仍要求独立新授权，不实现same-credit自动supersession。当前闭环针对同需求/同冻结计划的代码修复，不能暗改标准。
- API补新终态Preparation的真实usage持久化（unknown仍null，不回填历史），测试nonfinal cleanfail到后续repair期间的锁/额度/发布fence，提供有界安全中文失败摘要。
- Web补clean行为详情、每一历史Run报告入口、无Version准确文案；只有实际producer数据才显示轮次/下一步/余量，缺失即不猜。
