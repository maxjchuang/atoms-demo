# 咨询回答正文保真：最小修复

问题：普通咨询中出现“已发布源码/版本”，被部署正则误判为公网发布声明并整段替换；Agent/API又各追加交付事实，导致实际答案丢失或被历史缺口淹没。

策略：模型原答复独立作为正文，版本/asOf/来源/quality/部署状态使用现有结构化区块与交付报告。Agent不向consult/status正文注入宿主事实，API不向普通答复重复拼接长gaps或以无关部署说明覆盖正文。部署能力只依据可信分享输入/动作及真实宿主字段处理，来源/未核验网址守门保持。状态查询仍由宿主事实生成。

范围：不修改游戏、不扩大源码读取范围，不增加模型调用或重试额度，不回写旧消息。回归覆盖“已发布源码/版本”普通咨询、长gap与长正文尾部保留、明确分享宿主事实、网址拒绝和现有状态/报告展示。新回复生效，历史错误答复保持审计记录。
